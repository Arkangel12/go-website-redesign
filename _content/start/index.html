Install Go

        
Download and install Go on your computer. The installer sets up everything you need.


        

          
          
          
        


        

          

            1
            

              
Download the macOS installer:

              

                
                  Download Go for macOS →
                
              

            

          

          

            2
            
Open the downloaded .pkg file and follow the installer prompts.

          

          

            3
            
Verify the installation by opening Terminal and running:

            

              
go version

              
            

          

        


        

          

            1
            

              
Download the Windows installer:

              

                
                  Download Go for Windows →
                
              

            

          

          

            2
            
Open the downloaded .msi file and follow the installer prompts.

          

          

            3
            
Verify the installation by opening Command Prompt and running:

            

              
go version

              
            

          

        


        

          

            1
            
Remove any prior Go installation, then extract the archive to /usr/local:

            

              
rm -rf /usr/local/go && tar -C /usr/local -xzf go*.linux-amd64.tar.gz

              
            

          

          

            2
            
Add /usr/local/go/bin to your PATH in ~/.profile or ~/.bashrc:

            

              
export PATH=$PATH:/usr/local/go/bin

              
            

          

          

            3
            
Reload your shell config then verify:

            

              
go version

              
            

          

        

      

    

    

      
      
    

  


  
  

    

      

        
Step 3 of 5

        
Your first Go program

        
Let's write a real program on your machine. This takes about 5 minutes.


        
    
          
  1. 
            
    Create a module
    
            
    A Go project is called a module. Create a directory and initialize it:
    
            
    
              
    mkdir hello && cd hello && go mod init example/hello
    
              
            
    
          
    2. 
          
  2. 
            
    Write the code
    
            
    Create a file called hello.go with this content — run it in the playground to preview:
    
            
    
              
    
                hello.go
              
    
              
              
    
                
              
    
              
    
            
    
          
    3. 
          
  3. 
            
    Run it
    
            
    In your terminal, inside the hello directory:
    
            
    
              
    go run hello.go
    
              
            
    
            
    You should see: Hello, Gopher! Welcome to Go.
    
          
    4. 
          
  4. 
            
    Build an executable
    
            
    Compile to a standalone binary with go build:
    
            
    
              
    go build -o hello && ./hello
    
              
            
    
            
    Go compiles to a single, self-contained binary — no runtime to install.
